# Turn taking

该目录管理两类“正式回复之外的声音”：

- 用户仍在说话时的接话／附和：继续由已有停顿插入函数决定机会；session 前 3 轮
  基准概率 50%，第 4–6 轮 10%，完成 6 轮后回升到 30% 并保持。
- 用户句尾后的垫话交接：`short_ack_plan(实际音频秒数)` 等短音完整结束后再
  放行主回复；`SHORT_ACK` 是 350ms 短音的默认计划；
  `LONG_WORK_FILLER` 面向 COT／工具／查询。正文可以在后台继续生成和合成，但播放
  必须等浏览器确认长垫话完整结束，二者不重叠，也不提前截断垫话。

`generate_filler()` 通过当前回复模型生成可说出口的垫话，不泄露思维链或伪造查询结果；
`run_overlapped_handoff()` 保留短音的通用重叠原语。当前 `memory_cot` 路径已经接入
长垫话，并由 Web 播放完成回报控制正文放行；用户说话过程中的接话继续使用独立的
session 概率和冷却策略。
