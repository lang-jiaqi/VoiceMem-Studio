# Turn taking

该目录管理两类“正式回复之外的声音”：

- 用户仍在说话时的接话／附和：继续由已有停顿插入函数决定机会；session 前 3 轮
  基准概率 50%，第 4–6 轮 10%，完成 6 轮后回升到 30% 并保持。
- 用户句尾后的垫话交接：`short_ack_plan(实际音频秒数)` 在短音结束前 100ms
  启动主回复；`SHORT_ACK` 是 350ms 短音的默认计划；
  `LONG_WORK_FILLER` 面向 COT／工具／查询，目标约 4 秒，并在 3.8 秒启动主回复。

`generate_filler()` 通过当前回复模型生成可说出口的垫话，不泄露思维链或伪造查询结果；
`run_overlapped_handoff()` 负责并行播放与交接。现在实际运行的部分是用户说话过程中的
接话及其 session 曲线；句尾短音和长垫话的生成、时序接口已经实现，但当前 direct
回复没有“正在查询”的可靠状态，因此不会凭空播放。未来 `reply_modes/` 路由接入时，
把 COT／工具状态和播放函数交给本模块即可启用。
